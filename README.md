# Boîte à outils de gestion commerciale

## Présentation
Ce projet consiste à développer une boîte à outils de gestion commerciale en Python afin d'automatiser plusieurs calculs commerciaux et financiers.

## Fonctionnalités

- **marge.py** : calcul de la marge commerciale.
- **tva.py** : calcul de la TVA et du prix TTC avec un taux de 19 %.
- **interets.py** : calcul des intérêts simples et composés.
- **ventes.py** : calcul du total des ventes.

## Technologies utilisées
- Python
- Git
- GitHub
- Visual Studio Code

## Exécution
Pour lancer un programme, utiliser la commande suivante dans le terminal :

```bash
python marge.py
```

Remplacer `marge.py` par le nom du programme souhaité.
